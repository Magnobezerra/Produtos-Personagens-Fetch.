# Consumo de API com JavaScript

Projeto desenvolvido para praticar o consumo de APIs utilizando JavaScript e a exibição dinâmica de dados em uma tabela.

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap 5

## Funcionalidades

* Requisição de dados de uma API pública
* Exibição das informações em tabela
* Renderização dinâmica de imagens
* Interface responsiva com Bootstrap

## Estrutura do Projeto

```text
index.html
style.css
app.js
```

## Objetivos de Aprendizagem

* Trabalhar com requisições HTTP
* Consumir APIs REST
* Manipular o DOM com JavaScript
* Exibir dados de forma dinâmica

## Como Executar

1. Clone o repositório.
2. Abra o arquivo `index.html` no navegador.
